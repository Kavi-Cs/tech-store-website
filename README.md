# 🛒 Tech Store E-commerce Website

Welcome to the **Tech Store E-commerce Website**! This is a dynamic and responsive web application built to demonstrate real-world database connectivity, data rendering, and backend management.

🔗 **Live Demo:** [Click Here to View the Website](http://induwaratech.page.gd/index.php)

## 🚀 About This Project
This project is an e-commerce platform designed for a tech store. It allows users to browse through various tech products and view their details. The platform is powered by a PHP backend and a MySQL database to handle dynamic product data efficiently. It is built to be responsive and user-friendly.

## ✨ Features
* **Dynamic Product Display:** All products are fetched directly from the MySQL database.
* **Responsive Design:** Optimized for Mobile, Tablet, and Desktop screens.
* **Organized Codebase:** Clean structure with separate files for database connection.
