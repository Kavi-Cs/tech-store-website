# Tech Store Website 🛒

A simple and responsive E-commerce website built for a tech store using PHP and MySQL. This project demonstrates dynamic web development concepts, including database connectivity and data rendering.

🔗 **Live Demo:** [Click Here to View the Website](http://induwaratech.page.gd/index.php)

## ✨ Features
* Dynamic product display from the database.
* Responsive design (Mobile, Tablet, and Desktop friendly).
* Organized codebase with separate connection files.

## 🛠️ Technologies Used
* **Frontend:** HTML5, CSS3
* **Backend:** PHP
* **Database:** MySQL
* **Hosting:** InfinityFree
